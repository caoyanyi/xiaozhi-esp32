# 瓦力 ESP32-S3 首次上电与校准检查表

按顺序执行并逐项打勾。任何一步出现异常，都先断开舵机和电机电源，不要跳到下一步。

接线总表见：[接线与电源采购指南](wall-e-s3-wiring-and-power-zh-CN.md)。

## 0. 当前固件默认值

固件在检测到 PCA9685 后会立即输出各舵机的初始角度。第一次启动必须拆下舵盘或断开机械连杆，避免舵机回中时顶死机构。

| 通道 | 功能 | 允许角度 | 初始角度 | 软件反向 | 当前状态 |
|---:|---|---:|---:|---|---|
| CH0 | 左眼 | 70–110° | 90° | 否 | 启用 |
| CH1 | 右眼 | 70–110° | 90° | 是 | 启用 |
| CH2 | 左臂 | 30–150° | 40° | 否 | 启用 |
| CH3 | 右臂 | 30–150° | 40° | 是 | 启用 |
| CH4 | 下脖子 | 70–110° | 90° | 否 | 启用 |
| CH5 | 上脖子 | 65–115° | 90° | 否 | 启用 |
| CH6 | 转头 | 45–135° | 90° | 否 | 启用 |
| CH7 | 预留 | 60–120° | 90° | 否 | 禁用 |

这些只是保守起始值，不代表你的机械结构一定安全。最终值应根据实物校准后修改 `main/boards/wall-e-s3/wall_e_controller.cc`。

## 1. 断电检查

- [ ] 所有舵盘或机械连杆已拆下。
- [ ] 机器人已架空，左右车轮不接触桌面和地面。
- [ ] ESP32、舵机电源、电机电源全部断开。
- [ ] PCA9685 `VCC` 接 ESP32 3.3V，而不是外部 5V 舵机总线。
- [ ] PCA9685 `V+` 只接外部 5V。
- [ ] PCA9685 `OE` 已接 GND。
- [ ] OLED/PCA9685 SDA 接 GPIO41，SCL 接 GPIO42。
- [ ] L298P 的 ENA/IN1/IN2 接 GPIO8/9/10。
- [ ] L298P 的 ENB/IN3/IN4 接 GPIO11/12/13。
- [ ] 所有模块 GND 汇入公共地线。
- [ ] 舵机、电机的大电流线路没有经过面包板或杜邦线。
- [ ] 电源入口已经安装保险丝和总开关。
- [ ] 电解电容正负极方向正确。
- [ ] 万用表通断档检查 5V 与 GND 没有直接短路。

## 2. 只启动 ESP32 和逻辑电路

此阶段不要给 PCA9685 `V+` 和 L298P 电机端供电。

- [ ] 用 USB 启动 ESP32-S3。
- [ ] OLED 显示正常。
- [ ] 麦克风和扬声器语音交互正常。
- [ ] PCA9685 逻辑侧有约 3.3V。
- [ ] OLED 与 PCA9685 的 I²C 总线高电平不超过 3.3V。
- [ ] 固件状态没有持续重启或棕断电复位。

如果 PCA9685 在启动时未连接或未响应，固件会把舵机控制标记为不可用；接好后需要重新启动 ESP32。

## 3. 验证外部 5V 电源

先让外部电源空载工作：

- [ ] 空载输出电压为 4.9–5.1V。
- [ ] 电源极性与标签一致。
- [ ] 总开关可以完全切断 5V 输出。
- [ ] 保险丝和端子没有发热或松动。
- [ ] 2200–4700µF 电容接在 PCA9685 `V+` 与 `GND` 附近。

确认后关闭电源，再接入 PCA9685 `V+`。

## 4. 单个舵机回中

每次只接一个舵机，舵盘保持拆下状态：

1. 关闭外部 5V。
2. 把舵机插入对应 PCA9685 通道，核对 `GND / V+ / PWM` 方向。
3. 开启 ESP32，再开启舵机 5V。
4. 让舵机到初始位置；听到持续嗡鸣或发现发热时立即断电。
5. 断电后安装舵盘，使机械结构位于自然中位。
6. 重新上电，只做小范围动作。

## 5. 舵机动作验收

- [ ] “回到中间”时头部、眼睛和胳膊都没有顶住结构。
- [ ] “抬头”和“低头”方向正确。
- [ ] “看左边”和“看右边”方向正确。
- [ ] 左右胳膊动作没有互相相反或撞击身体。
- [ ] 左右眼动作方向符合机械结构。
- [ ] 连续动作 30 秒后，舵机和电源线没有明显发热。
- [ ] 多个舵机同时动作时，ESP32 没有重启、OLED 没有闪烁。

## 6. L298P 与电机测试

电机测试时仍保持机器人架空：

- [ ] 已确认电机额定电压。
- [ ] 已确认 L298P `5V` 端是输入还是输出。
- [ ] ENA/ENB 跳线已按 PWM 控制要求处理。
- [ ] 左右电机两端分别接到 OUT1/OUT2、OUT3/OUT4。
- [ ] 每个电机两端并联 0.1µF 陶瓷电容。
- [ ] 先以最低可用速度运行 0.5–1 秒。
- [ ] 发送“停止”后两个电机立即停转。
- [ ] 行走命令超过设定时间后会自动停止。
- [ ] 前进时两个车轮方向正确。
- [ ] 左转和右转方向正确。
- [ ] L298P 散热片、电机线和端子没有快速升温。

## 8. 整机落地前的停止条件

以下任一项不满足，就不要让机器人落地行走：

- [ ] 保险丝、总开关和急停位置容易触及。
- [ ] 已理解语音“停止”不能替代物理总开关或急停。
- [ ] `stop` 命令连续测试 10 次都能工作。
- [ ] 断开 Wi-Fi 或停止语音后，电机不会持续运行。
- [ ] 电源线、端子、降压模块和 L298P 不会异常发热。
- [ ] 舵机机械限位已写入代码，不依靠人手阻挡。
- [ ] 电池固定牢靠，不会被轮子、舵机或金属件刺破。
- [ ] 所有裸露焊点和电源端子已经绝缘。
