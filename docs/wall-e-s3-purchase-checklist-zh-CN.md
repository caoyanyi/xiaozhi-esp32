# 瓦力 ESP32-S3 采购清单

这份清单按“先在桌面安全跑通，再改成电池移动”安排。已经拥有的 ESP32-S3、OLED、PCA9685、L298P 和舵机不需要重复购买。

完整接线说明见：[接线与电源采购指南](wall-e-s3-wiring-and-power-zh-CN.md)。

## 电机部分暂缓购买的材料

目前缺少直流电机的完整铭牌和堵转电流，以下材料不能只按“L298P 5V”下单：

- 电机电源降压模块
- 电机保险丝规格
- 是否继续使用 L298P
- 是否需要换 TB6612FNG、DRV8833 或更大电流驱动器

|---|---|---|

| 空载电流 |  |  |
| 堵转电流或厂家给出的最大电流 |  |  |

电机驱动器的每路持续电流应高于对应电机的正常工作电流，峰值能力应覆盖启动/堵转电流。若电机堵转电流超过 L298P 板可可靠承受的范围，应先更换驱动器，不要通过加大保险丝硬撑。

## 不要购买或不要这样使用

- 不要购买 5V/1A、5V/2A 小电源给 7 个舵机供电。
- 不要用 MB102 面包板电源模块给舵机或电机供电。
- 不要用普通杜邦线承载舵机总电流。
- 不要购买裸露 220V 接线端子的开放式电源给新手桌面使用。
- 不要把两个 5V 稳压模块的输出直接并联。
- 只有一个 OLED 时，不需要购买 TCA9548A I²C 多路复用器。
- 不要把 2S 电池直接接到 PCA9685 `V+` 或 MG90S/MG92B。

## 到货检查

收到材料后先不连接 ESP32：

1. 检查电源外壳、线材和插头无破损。
2. 用万用表确认电源输出正负极和空载电压。
3. 调整型降压模块必须先空载调到 5.0V，再连接任何模块。
4. 检查 PCA9685 的 `VCC`、`V+`、`GND` 丝印和舵机插针方向。
5. 检查 L298P 的逻辑 5V、电机电源和 ENA/ENB 跳线说明。
6. 给每根电源线两端贴标签，至少标明 `5V`、`GND`、`MOTOR+`。
